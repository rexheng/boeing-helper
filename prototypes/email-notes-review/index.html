Prototypes · discussion only

Elevate “Update from email / notes”

Today the paste → review flow is a toolbar toggle that expands a stacked panel above the sheet. You scroll the hunk list, then scroll again to see the live document. These prototypes make intake a centrepiece and keep source + proposal in view together.

Plan (before we build)

1 · Centrepiece intake

Not a collapsible

On the Attendee dashboard tab, the paste surface is always present as a hero band — brand-forward, full-bleed within the materials canvas — not a secondary “show LLM” button.

  • Subtitle: outcome language only (“Paste an email or notes — we’ll propose roster updates you can accept.”)
  • No provider/API name in UI copy
  • Demo affordance: “Try sample email” loads the synthetic message below
2 · Wow for the demo

Animate extraction, not chrome

After Generate, don’t dump a static list. Stage a short “reading → extracting → proposing” beat:

  • ~1.2s scan line over the paste
  • People / travel / role chips fly out of the text
  • Hunks cascade in; matching Excel cells pulse yellow
  • Optional: highlight source spans in the email that drove each hunk
3 · Review ergonomics

Side-by-side by default

Recommended default: docked composer + live sheet (Layout B), then after generate flip to changes | document (Layout A). Sticky Accept bar. No vertical chase.

  • Clicking a hunk scrolls/highlights the cell in the sheet
  • Mobile: stacked with sticky doc peek

Decisions I’d like from you

Layout
  • B (docked) — best ergonomics for paste + sheet; my recommendation
  • A — cleanest review moment after generate
  • C — max transparency (source spans), denser
  • D — least layout change; still scroll-y on small screens
  • Hybrid: B for intake → A for review (same chrome, left rail swaps)
Wow budget
  • Chip cascade + cell pulse — high demo value, modest build
  • Source-span linking (email sentence ↔ hunk) — higher build, great for trust
  • File drop (.eml/.txt) — nice later; paste is enough for SEA demo
  • Keep motion to 2–3 beats; no purple glow / confetti
